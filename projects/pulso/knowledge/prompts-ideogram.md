# Prompts de Ideogram para afinar la marca PULSO

Para copiar y pegar en ideogram.ai. Ideogram todavía no está conectado al Centro de mando, así que por ahora se generan a mano y las que te gusten se suben a **Crear → Biblioteca** para revisarlas.

Base: `knowledge/marca.md` (paleta, tipografía, logo y estilo). Todo lo que sale de aquí es **propuesta**: el logo final, la manuscrita y los colores por pilar siguen **por confirmar** hasta que los apruebes.

## Cómo usarlos

- Pega el prompt tal cual (en inglés: Ideogram entiende mejor así). El texto entre comillas es lo que aparece escrito en la imagen.
- **Estilo:** Design para logos y piezas con texto; Realistic para fotos de ambiente.
- **Magic Prompt:** apágalo, para que no cambie los colores ni el texto.
- **Proporción:** la que indica cada prompt.
- Si Ideogram tiene campo de *negative prompt*, pega el de abajo. Si no, ignóralo.
- Genera 4 opciones por prompt y quédate con 1 o 2.

**Negative prompt (para todos):** `gradients, 3D bevel, glossy, neon, drop shadows, rounded corners, cartoon mascot, clip art, extra text, misspelled words, watermark, cluttered background`

## Qué hacer con las que te gusten

1. Súbelas en **Crear → Biblioteca** con la categoría "Otro" y la descripción "Ideogram: prompt 1A" (o el que sea).
2. Elige la que más te guste y dime "esta". La paso a decisión en el Centro de mando y, si la apruebas, actualizo `marca.md`.
3. **Ojo con el logo:** si eliges uno de Ideogram, conviene redibujarlo en vector antes de imprimir y revisar que no se parezca a otra marca registrada antes de usarlo en vasos o en el carrito.
4. Las imágenes de vasos, carrito y merch son de concepto. No se publican como si fueran el producto real.

Si conectamos Ideogram por API más adelante (necesita clave y un servidor), estos mismos prompts quedan como plantilla para que el agente los use solo.
