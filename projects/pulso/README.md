# Proyecto PULSO Coffee & More

Carpeta independiente del proyecto PULSO. Nada de aquí se mezcla con otros proyectos.

Identificador del proyecto: `pulso`. Espacio de datos en el Centro de mando: colecciones raíz (PULSO fue el primer proyecto). Los proyectos nuevos usan `proyectos/<id>/<colección>`.

| Carpeta | Qué hay |
| --- | --- |
| `knowledge/` | `marca.md` (solo lectura), `menu.md`, `reglas.md`, `conexiones.md`, `decisiones-fundadora.md`, `ejemplos/` |
| `agents/` | Fichas de los agentes, copiadas de `templates/agents/` y ajustadas a PULSO |
| `skills/` | Procedimientos repetibles de PULSO |
| `board/` | Esquema del tablero, conexión y exportes |
| `decisions/` | Historial de decisiones exportado: una entrada por decisión |
| `videos/` | Carpetas de trabajo del Editor de vídeos (los vídeos no se suben al repo) |
| `library/` | Índice de imágenes y videos aprobados (los archivos viven en la biblioteca del Centro de mando) |
| `web/` | Web de venta del piloto |

Las rutas dentro de estos archivos (`knowledge/…`, `skills/…`, `board/…`) son relativas a esta carpeta. El código del Centro de mando está en `dashboard/`, en la raíz del repo.
